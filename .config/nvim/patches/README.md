# Neovim plugin patches

Patches applied after plugin install/update via Packer's `run` hook.

- **avante-diff-view.patch** – Fixes ACP agent diff display in Avante chat (supports oldText/newText, edits array, etc.)
- **avante-mcp-mcphub.patch** – Allows `mcp_servers` to be a function (for mcphub/Claude Code compatibility)
